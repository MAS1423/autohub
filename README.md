# AutoHub — أوتو هَب

**AutoHub** منصة دليل معارض سيارات مبنية بـ React وExpress وtRPC. أُعدّت هذه النسخة لتعمل محليًا مباشرة بعد فك الضغط وتثبيت الاعتماديات، مع بيانات تجريبية وصور مضمّنة داخل المشروع؛ لذلك لا تحتاج إلى MySQL أو S3 أو مفاتيح خدمات خارجية لتصفح المنصة وتجربة التسجيل وتسجيل الدخول والاستفسارات.

## المتطلبات

| المتطلب | الإصدار المقترح | الغرض |
|---|---:|---|
| Node.js | 20 أو أحدث | تشغيل الواجهة والخادم |
| pnpm | 10 | تثبيت الاعتماديات وتشغيل الأوامر |
| MySQL أو MariaDB | اختياري | مطلوب فقط عند اختيار `DATA_MODE=mysql` |

## تشغيل سريع محليًا

نفّذ الأوامر التالية من مجلد المشروع. عند أول تشغيل سينشئ التطبيق تلقائيًا ملف بيانات محليًا في `data/autohub.local.json` ويضيف بيانات العرض والحسابات التجريبية.

```bash
pnpm install --frozen-lockfile
cp .env.example .env
pnpm dev
```

بعد بدء الخادم افتح العنوان المعروض في الطرفية، وهو عادةً [http://localhost:3000](http://localhost:3000). إذا كان المنفذ 3000 مستخدمًا، يختار التطبيق أول منفذ متاح ويطبعه بوضوح.

> يعمل الوضع الافتراضي `DATA_MODE=local` دون قاعدة بيانات خارجية. لا تضف `DATABASE_URL` ولا تشغّل ترحيلات Drizzle ما لم ترد التحول إلى MySQL عمدًا.

## الحسابات التجريبية

| الصلاحية | البريد الإلكتروني | كلمة المرور | الاستخدام |
|---|---|---|---|
| مدير | `admin@autohub.sa` | `admin123` | اختبار لوحة الإدارة |
| صاحب معرض | `dealer@autohub.sa` | `dealer123` | اختبار لوحة المعرض والإضافات |
| مستخدم | `user@autohub.sa` | `user123` | اختبار الحساب العادي |

تُنشأ الحسابات مع بيانات العرض تلقائيًا. لإرجاع بيانات الوضع المحلي إلى حالتها التجريبية الأصلية، شغّل الأمر التالي. سيحذف هذا الأمر السجل المحلي الحالي فقط، ولا يؤثر في ملفات المصدر أو الصور.

```bash
pnpm seed
```

## الصور والملفات المرفوعة

تُخدم جميع صور العرض من `client/public/assets/` عبر مسارات محلية مثل `/assets/car-suv.jpg`، ولا تعتمد بيانات العرض على Unsplash أو GitHub أو أي رابط صور خارجي. حُوّلت الصور إلى JPEG وPNG متوافقين وصُغّرت لتقليل وقت التحميل محليًا.

أما الملفات التي يرفعها المستخدم فتُحفظ افتراضيًا في `uploads/` وتظهر عبر المسار `/uploads/*`. تستطيع اختبارها من صفحة لوحة المعرض بعد تسجيل الدخول بحساب صاحب المعرض. لا يدخل مجلدا `uploads/` و`data/` في التحكم بالمصدر لأنهما يحتويان بيانات تشغيل محلية قابلة للتغيير.

## أوامر المشروع

| الأمر | النتيجة |
|---|---|
| `pnpm dev` | تشغيل بيئة التطوير مع إعادة التحميل التلقائي |
| `pnpm build` | بناء الواجهة والخادم للإنتاج في `dist/` |
| `pnpm start` | تشغيل ناتج البناء بعد تنفيذ `pnpm build` |
| `pnpm check` | فحص TypeScript دون توليد ملفات |
| `pnpm test` | تشغيل اختبارات Vitest |
| `pnpm seed` | إعادة تهيئة بيانات الوضع المحلي التجريبية |
| `pnpm seed:mysql` | إنشاء الحسابات التجريبية في MySQL عند اختيار وضع MySQL |
| `pnpm db:push` | إنشاء وتنفيذ ترحيلات Drizzle عند استخدام MySQL فقط |

## إعدادات البيئة

انسخ `.env.example` إلى `.env` ثم عدّل القيم عند الحاجة. في الاستخدام المحلي العادي اترك `DATA_MODE=local` كما هو.

| المتغير | القيمة الافتراضية | الوصف |
|---|---|---|
| `DATA_MODE` | `local` | وضع بيانات JSON محلي. استخدم `mysql` فقط لخادم قاعدة بيانات فعلي. |
| `LOCAL_DATA_FILE` | `data/autohub.local.json` | موقع البيانات المحلية القابلة للاستمرار بين عمليات التشغيل. |
| `PORT` | `3000` | منفذ Express المفضل. |
| `JWT_SECRET` | قيمة تطويرية | سر توقيع جلسات تسجيل الدخول؛ غيّره قبل النشر. |
| `UPLOAD_DIR` | `uploads` | مجلد الملفات التي يرفعها المستخدم محليًا. |
| `GOOGLE_MAPS_API_KEY` و`VITE_GOOGLE_MAPS_API_KEY` | فارغ | اختياريان لخريطة Google التفاعلية. |
| `S3_*` | فارغ | اختياري لتبديل التخزين من القرص المحلي إلى خدمة متوافقة مع S3. |

## وضع MySQL الاختياري

يدعم المشروع MySQL 8+ وMariaDB 10.6+ وTiDB. عند الرغبة في تشغيل هذا الوضع، غيّر `DATA_MODE` وأضف رابط الاتصال، ثم أنشئ المخطط والبيانات التجريبية.

```env
DATA_MODE=mysql
DATABASE_URL=mysql://root:password@localhost:3306/autohub
```

```bash
pnpm db:push
pnpm seed:mysql
pnpm dev
```

## البنية الأساسية

```text
client/                 واجهة React وملفات الصور المحلية
server/                 Express وtRPC وطبقة البيانات
server/localStore.ts    تخزين JSON محلي افتراضي مع بيانات تجريبية
drizzle/                مخطط MySQL وعمليات Drizzle
uploads/                صور وملفات يرفعها المستخدم أثناء التشغيل
data/                   بيانات JSON محلية تتولد تلقائيًا
```

## ملاحظات التشغيل

يظل Google Maps وS3 وميزات الذكاء الاصطناعي اختيارية؛ لن توقف هذه الخدمات التطبيق عن التشغيل عند غياب مفاتيحها. أما صفحات الدليل والسيارات والتفاصيل وتسجيل الدخول والاستفسارات ولوحات التحكم فتعمل بالبيانات المحلية المضمّنة في الوضع الافتراضي.
